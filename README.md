# Droplet Formation in Microfluidic Channels

Axisymmetric Stokes-flow solver for a growing droplet in a cylindrical microchannel. The code returns equatorial velocity profiles, interfacial shear, independent phase pressure gradients, and the force balance that sets droplet size and the drip–slug transition.

The hydrodynamics follow Svetlov & Abiev, *Chemical Engineering Science* **235**, 116493 (2021).

## Problem statement

A dispersed-phase droplet occupies $0 \le r \le R_d$ inside a continuous-phase film $R_d \le r \le R$. The practical questions are:

- How do $Q_1$ and $Q_2$ shape the equatorial velocity field?
- When do detaching forces overcome interfacial tension?
- Is the detached object a spherical drop or a liquid slug?

## Mathematical model

Under creeping, steady, axisymmetric flow the axial momentum equation reduces to

```math
\frac{1}{r}\frac{\mathrm{d}}{\mathrm{d}r}\left(r\frac{\mathrm{d}u_i}{\mathrm{d}r}\right)
=
\frac{1}{\mu_i}\frac{\partial p_i}{\partial x}
```

Boundary conditions:

- wall no-slip: $u_1(R)=0$
- centreline symmetry: $u_2'(0)=0$
- velocity continuity: $u_1(R_d)=u_2(R_d)=U_{tp}$
- shear continuity: $\mu_1 u_1'(R_d)=\mu_2 u_2'(R_d)$

The two pressure gradients are independent. They are fixed by the imposed flow rates

```math
Q_1 = 2\pi\int_{R_d}^{R} u_1 r\,\mathrm{d}r,\qquad
Q_2 = 2\pi\int_{0}^{R_d} u_2 r\,\mathrm{d}r
```

Detachment is estimated from the equatorial force balance

```math
F_{\mathrm{tot}} = F_{\Delta p} + F_s - F_r = 0
```

with $F_r=\pi d_d\sigma$, $F_s=\tau(R_d)A_d$, and $F_{\Delta p}=(\partial p_2/\partial x)V_d$. Equilibrium, critical, and real diameters follow from that balance and the neck-collapse time $t_{\mathrm{col}}=d_c^3/Q_1$.

Default properties match the water–cyclohexane micromixer: $d_c=300\,\mu\mathrm{m}$, $\mu_1=2.24\,\mathrm{mPa\cdot s}$, $\mu_2=0.97\,\mathrm{mPa\cdot s}$.

## Computational methodology

1. **Analytical field** — integrate the Stokes operator, apply the four boundary conditions, and close the system with the two flow-rate integrals (6 × 6 linear solve for $P_1$, $P_2$, $U_{tp}$, $c_{11}$, $c_{21}$, $c_{22}$).
2. **Chebyshev collocation** — the same BVP on Gauss–Lobatto nodes, with Clenshaw–Curtis quadrature for $Q_1$ and $Q_2$. Used as an independent verification of the closed form.
3. **Force scan** — evaluate $F_{\mathrm{tot}}(d_d)$ and interpolate the zero to obtain $d_{\mathrm{eq}}$. Compare with $d_{\mathrm{crit}}$ to classify slug vs drip.

The spectral differentiation matrix is Trefethen’s Chebyshev–Gauss–Lobatto form, including the endpoint entries $\pm(2N^2+1)/6$.

## Features

- Closed-form two-phase velocity field
- Independent $\partial p_1/\partial x$ and $\partial p_2/\partial x$ from $Q_1$, $Q_2$
- Chebyshev verification of the same boundary-value problem
- Force-balance estimates of $d_{\mathrm{eq}}$, $d_{\mathrm{crit}}$, $d_{\mathrm{real}}$
- Static HTML results page with KaTeX-rendered equations
- Input validation for geometry, viscosities, flow rates, and collocation order

```bash

```

or:

```bash
droplet-formation --output results
```

Open the results UI:

```bash
open results/index.html
```

On Linux use `xdg-open results/index.html`. The page loads KaTeX from a CDN, so viewing it requires network access once.

Notebooks:

- `notebooks/hydrodynamic_solver.ipynb` — analytical field, spectral check, force balance
- `notebooks/chebyshev_collocation.ipynb` — differentiation-matrix kernel

Tests:

```bash
pytest
```

Minimal API usage:

```python
from droplet_formation import Channel, mlh, solve_analytical, solve_chebyshev

ch = Channel()
Rd = 0.6 * ch.R
fld = solve_analytical(ch.R, Rd, ch.mu1, ch.mu2, mlh(10), mlh(1))
chb = solve_chebyshev(ch.R, Rd, ch.mu1, ch.mu2, mlh(10), mlh(1), N=50)

print(fld.P1, fld.P2, fld.Utp)
print(float(fld.u2(0.0)))
print(fld.reconstruct_Q())
```

Reference hydrodynamic case, $Q_1=10\,\mathrm{ml/h}$, $Q_2=1\,\mathrm{ml/h}$, $d_d=0.6\,d_c$:

| Quantity | Value |
|---|---|
| $\partial p_1/\partial x$ | $-2.076\times 10^{5}\,\mathrm{Pa/m}$ |
| $\partial p_2/\partial x$ | $+6.658\times 10^{4}\,\mathrm{Pa/m}$ |
| $U_{tp}$ | $0.0804\,\mathrm{m/s}$ |
| $u_2(0)$ | $-0.0586\,\mathrm{m/s}$ |

The pressure gradients have opposite sign, so the droplet core reverses relative to the film. Raising $Q_1$ accelerates the film and can invert the core; raising $Q_2$ mainly changes the droplet interior.

Force balance at $Q_1=4.456\,\mathrm{ml/h}$, $Q_2=0.518\,\mathrm{ml/h}$, $\sigma=2.636\,\mathrm{mN/m}$:

| Diameter | Value |
|---|---|
| $d_{\mathrm{eq}}$ | $289\,\mu\mathrm{m}$ |
| $d_{\mathrm{crit}}$ | $276\,\mu\mathrm{m}$ |
| $d_{\mathrm{real}}$ | $311\,\mu\mathrm{m}$ |

Here $d_{\mathrm{eq}}>d_{\mathrm{crit}}$, so the detached object is a slug. Increasing $Q_1$ lowers $d_{\mathrm{eq}}$ and raises $d_{\mathrm{crit}}$; the curves cross at the slug → drip boundary.

Recovered flow rates and Chebyshev velocities agree with the closed form to $\sim 10^{-14}$.

## Assumptions and limitations

- Steady creeping flow; inertia and gravity are neglected.
- The droplet is treated as spherical; hydrodynamics are evaluated only in the equatorial plane.
- Shear on the full surface is approximated by the equatorial value, so $F_s$ is an upper bound.
- $F_{\Delta p}$ uses $\partial p_2/\partial x$, not the local film gradient.
- No empirical correction factor is applied to $F_s$; sizes are the model as written, not a fitted flow map.
- Neck-collapse time follows Cubaud’s $t_{\mathrm{col}}=d_c^3/Q_1$.
